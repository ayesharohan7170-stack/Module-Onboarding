What is the purpose of a README file?

A README is the first file people read in a project. It explains what the project does, how to install and run it, and how to contribute, so newcomers can get started without asking anyone.

What is the purpose of a wireframe?

A wireframe is a simple sketch of a page layout. It lets you plan structure and content placement before writing code, saving time and avoiding rework.
